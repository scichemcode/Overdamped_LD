What you are watching

The top panel is the potential U(x) = Eb[(x/d)² − 1]² with the particle on it. The bottom panel traces its position over time. In the overdamped limit there is no inertia: each step is a drift down the slope plus a Gaussian kick.

xj+1 = xj − (Δt/ζ)·U′(xj) + √(2DΔt)·ξj,   ξj ~ N(0,1),   D = kBT/ζ

Every animation uses the same sequence of random kicks, so the only difference between them is the barrier. A hop is counted when the particle reaches the far well (|x| ≥ 0.5), so jitter near the top does not count.

The wait between hops grows as eEb/kBT: each extra kBT of barrier makes a hop about 2.7 times rarer. At the higher barriers the expected wait is longer than the whole clip, so the particle stays in the left well.

Animations are rendered with matplotlib by overdamped-ld web from the Overdamped_LD package.
