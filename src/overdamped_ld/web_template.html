What is being computed

The potential is U(x) = Eb[(x/d)² − 1]². In the overdamped limit the particle has no inertia, so each time step is a drift down the slope plus a Gaussian kick (Euler–Maruyama):

xj+1 = xj − (Δt/ζ)·U′(xj) + √(2DΔt)·ξj,   ξj ~ N(0,1),   D = kBT/ζ

Only the ratio Eb/kBT sets how often the particle hops: the mean wait grows roughly as eEb/kBT. Friction and well separation only stretch the time axis. Keeping the seed fixed reuses the same random kicks, so you can change one parameter and see its effect alone.

The histogram beside the trajectory fills in as the run plays. The dashed curve is the Boltzmann distribution e−U/kBT, which a long enough run should match. A hop is counted when the particle reaches the other well (|x| ≥ d/2). Large time steps make the integration inaccurate, and the page warns you when that happens.

The simulation is overdamped_ld v__VERSION__, run by Pyodide. The page is regenerated with overdamped-ld web.
